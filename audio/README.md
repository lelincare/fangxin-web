# 背景音樂檔案放這裡

請將下載好的音樂檔案重新命名為 `bgm.mp3`，放進這個資料夾即可。

網站程式碼已經寫好會讀取 `audio/bgm.mp3`，只要檔名跟路徑對就會自動生效，不需要改任何程式碼。

## 建議免費授權音樂素材網站

- **Pixabay Music**（最推薦）：https://pixabay.com/music/ — 完全免費、不需標註來源、可商用
- **YouTube Audio Library**：https://studio.youtube.com 內建功能 — 完全免費，部分曲目需標註來源
- **Bensound**：https://www.bensound.com — 免費版需標註來源

## 建議搜尋關鍵字

`calm` `piano` `relax` `warm` `gentle` — 適合長照機構溫馨、放鬆的調性。

## 注意事項

- 檔案大小建議控制在 5MB 以內，避免網站載入太慢
- 格式使用 `.mp3` 即可，網站程式碼已預設這個格式
- 網站設計為「使用者手動按播放鍵」才會播放，不會自動播放打擾訪客
